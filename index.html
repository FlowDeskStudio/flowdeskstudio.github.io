Release Standard

FlowDesk Studio is reviewing its workbooks against a stricter release process.

⚡

Are the spreadsheet products currently available?
No. Paid products and free workbook downloads are temporarily unavailable while the exact files undergo functional, compatibility, and security review.
Will Google Sheets compatibility be supported?
Compatibility claims will be published only after the final workbook is imported and tested separately in Google Sheets.
When will downloads return?
Downloads will return only after the exact customer-facing files pass the required release checks.
Which Excel versions will be supported?
Supported versions will be listed after testing is completed. A successful test in one spreadsheet application will not be treated as proof of compatibility in another.
Why were the free downloads paused?
Two differently named download URLs were found to contain identical workbook bytes. Promotion is paused until each file is identified, corrected if necessary, and tested.
