# ログイン機能付き 会員ページ

Node.js だけで動く会員サイトです。外部パッケージのインストールは不要です。

## 起動方法

Node.js 18 以上が必要です。

```
cd login
node server.js
```

ブラウザで http://127.0.0.1:3000 を開きます。「新規登録」でアカウントを作ると、そのまま会員ページへ移動します。

## できること

| 画面 | URL | 内容 |
| --- | --- | --- |
| ログイン | `/login` | メールアドレスとパスワードでログイン |
| 新規会員登録 | `/register` | お名前・メールアドレス・パスワードを登録 |
| 会員ページ | `/members` | ログインした人だけが見られるページ（お知らせ、アカウント情報、パスワード変更） |
| ログアウト | ヘッダーのボタン | セッションを破棄してログイン画面へ戻る |

ログインしていない状態で `/members` を開くと、ログイン画面へ移動します。

## ファイル構成

```
login/
├── server.js         サーバー本体（画面・ログイン処理・セッション管理）
├── public/style.css  見た目（ダークモード・スマートフォン対応）
├── package.json      `npm start` でも起動できるようにする設定
├── .gitignore        会員データをコミットしないための設定
└── data/users.json   会員データ（初回登録時に自動で作られる）
```

## セキュリティ対策

- パスワードは scrypt（ソルト付き）でハッシュ化して保存します。平文では保存しません。
- セッション Cookie は `HttpOnly` と `SameSite=Lax` を付けて発行します。ログイン、ログアウト、パスワード変更のたびにセッション ID を作り直します。
- 送信フォームはすべて CSRF トークンと Origin ヘッダーで検査します。
- ログインに失敗し続けると一時的にロックします（同じメールアドレスで 15 分に 5 回、同じ IP で 15 分に 30 回まで）。
- ログインに失敗したときは、メールアドレスとパスワードのどちらが違ったかを区別せずに表示します。登録されていないメールアドレスでも処理時間がほぼ同じになるようにしています。
- セッションは、30 分間操作がないとき、またはログインから 12 時間経ったときに失効します。
- パスワードを変更すると、ほかの端末のログインもすべて解除されます。
- Content-Security-Policy でスクリプトの実行を全面的に禁止しています（このサイトは JavaScript を使っていません）。ほかに `X-Frame-Options` などのセキュリティヘッダーも付けています。
- 画面に表示する値はすべて HTML エスケープしています。

## 設定（環境変数）

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けポート |
| `HOST` | `127.0.0.1` | 待ち受けアドレス。ほかの端末からアクセスさせる場合は `0.0.0.0` |
| `SITE_NAME` | `メンバーズ` | ヘッダーやタイトルに出るサイト名 |
| `COOKIE_SECURE` | なし | `1` にすると Cookie に `Secure` を付けます（HTTPS 公開時は必ず設定） |
| `TRUST_PROXY` | なし | `1` にすると `X-Forwarded-For` を見て接続元 IP を判定します（リバースプロキシの背後に置く場合のみ） |
| `DATA_DIR` | `./data` | 会員データの保存先 |

## カスタマイズ

- 会員ページのお知らせは、`server.js` の先頭にある `MEMBER_NEWS` を書き換えると差し替わります。
- 色は `public/style.css` の先頭にある `:root` の変数でまとめて変えられます。

## 公開する前に

このまま社内や手元で試す分には十分ですが、インターネットに公開する場合は次の点を確認してください。

- HTTPS（nginx などのリバースプロキシ経由）で公開し、`COOKIE_SECURE=1` を設定する。
- セッションはメモリ上にあるため、サーバーを再起動すると全員ログアウトします。複数台で動かす場合は Redis などへの置き換えが必要です。
- 会員データは JSON ファイルです。会員が増える場合はデータベースへの移行を検討してください。
- パスワード再設定（メール送信）やメールアドレスの確認は含まれていません。必要ならメール送信の仕組みと合わせて追加してください。
