# お問い合わせフォーム

入力 → 確認 → 完了 の3画面で、送信された内容を指定のメールアドレスへ届ける PHP 製のフォームです。
データベースや外部ライブラリは使いません。

## 動作要件

- PHP 7.4 以上（8.x でも動きます）
- mbstring 拡張（日本語のレンタルサーバーなら通常は有効）
- サーバーで `mail()` 関数が使えること（エックスサーバー、さくら、ロリポップ等の一般的なレンタルサーバー）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.php` | 1. 入力画面（入力チェックもここで行います） |
| `confirm.php` | 2. 確認画面 |
| `send.php` | 送信処理（画面なし） |
| `thanks.php` | 3. 完了画面 |
| `config.php` | 設定（送信先アドレスなど） |
| `lib.php` | 共通処理 |
| `style.css` / `script.js` | 見た目／文字数カウンター・二重送信防止 |
| `.htaccess`, `data/` | 内部ファイルの保護、送信制限の記録置き場 |

## 設置手順

1. `config.php` を開き、次の項目を書き換えます。
   - `site_name` … サイト名
   - `to` … お問い合わせを受け取るアドレス（複数可）
   - `from_address` … 送信元アドレス。**フォームを置くサイトと同じドメイン**のアドレスにしてください（例: `no-reply@あなたのドメイン`）
   - `from_name` … 送信者名
   - `secret` … 長いランダムな文字列
   - 必要に応じて `categories`（種別の選択肢）、`privacy_policy_url`、`auto_reply`
2. `contact` フォルダごとサーバーへアップロードします。
3. `data` フォルダに PHP から書き込めるようにします（パーミッション 700 または 755。多くのサーバーでは変更不要です）。
4. ブラウザで `https://あなたのドメイン/contact/` を開き、実際に送信してメールが届くか確認します。

`to` や `from_address` が `example.com` のままだと、画面に管理者向けの注意が出て、送信は受け付けません。

## 届くメール

- 件名: `[サイト名] お問い合わせ（種別）お名前 様`
- 本文: 入力内容、送信日時、送信元IP、ブラウザ情報
- Reply-To にお客様のアドレスが入るので、そのまま「返信」すればお客様へ届きます。
- 文字コードは UTF-8 です（機種依存文字や絵文字も文字化けしにくい設定）。

`auto_reply` を `true` にすると、お客様にも受付確認メールが届きます。
ただし、他人のアドレスを入力されるとその人に届いてしまうため、既定では `false` にしています。

## メールサーバーなしで動作確認する

`config.php` の `mail_mode` を `'log'` にすると、メールは送られず `data/mail.log` に書き出されます。
手元のパソコンで PHP が使える場合は、`contact` フォルダで次を実行し、`http://localhost:8000/` を開いて試せます。

```
php -S localhost:8000
```

確認が終わったら `mail_mode` を `'mail'` に戻し、`data/mail.log` を削除してください（個人情報が含まれます）。

## セキュリティ・スパム対策

- CSRF トークン（他サイトからの不正な送信を拒否）
- メールヘッダーインジェクション対策（1行の項目は改行・制御文字を除去、アドレスを厳格にチェック）
- 出力時のエスケープ（XSS 対策）と Content-Security-Policy などのセキュリティヘッダー
- ボット対策: 画面に見えない入力欄（ハニーポット）、画面表示から数秒以内の送信を拒否、本文の URL 数の上限
- 連投対策: 同じブラウザからは60秒おき、同じ IP からは1時間に5回まで（`config.php` で変更可）
  - IP アドレスはそのまま保存せず、`secret` を鍵にしたハッシュ値で `data/ratelimit.json` に記録します
- 二重送信防止（ボタンの連打、送信後の再読み込み）

## うまく動かないとき

- **メールが届かない**: 迷惑メールフォルダを確認してください。`from_address` がサイトと別ドメインだと届きにくくなります。ドメインの SPF 設定も確認してください。
- **「送信に失敗しました」と出る**: サーバーが `-f` オプションを許可していない可能性があります。`use_envelope_from` を `false` にして試してください。それでも失敗する場合はサーバーのエラーログ（`[contact]` で始まる行）を確認してください。
- **500 エラーになる**: サーバーが `.htaccess` の `Require` 指定を許可していない可能性があります。`contact/.htaccess` を削除して試してください（`data/.htaccess` は残すことをおすすめします）。
- **Nginx の場合**: `.htaccess` は効かないので、`data/` ディレクトリと `*.log` `*.json` `*.md` へのアクセスを Nginx の設定で拒否してください。
- **SMTP 認証が必須のサーバー**: このフォームは PHP の `mail()` を使います。SMTP 認証でしか送れない環境では、PHPMailer などに `send_mail()`（`lib.php`）を差し替えてください。
