# 画像掲示板

画像を投稿して、返信で会話できる掲示板です。
追加のインストールは不要で、Node.js の標準機能だけで動きます。

## できること

- 画像つきの投稿（タイトル・本文・名前は任意、画像は必須）
- 投稿への返信（本文か画像のどちらかがあれば送れます）
- 画像の選び方は 3 通り：クリックで選ぶ、ドラッグ＆ドロップ、貼り付け（Ctrl + V）
- 大きな画像は自動で縮小（長い辺 2048px まで・5MB 以内）
- 撮影場所などの情報（メタデータ）を取り除いてから送信（GIF はアニメーションを保つため、そのまま送ります）
- 一覧はカード形式で表示。下までスクロールすると続きを読み込みます
- タイトル・本文・名前・返信を対象にした検索（スペース区切りで AND 検索）
- 画像の拡大表示
- 削除キーによる投稿・返信の削除（管理者キーを設定すれば、どの投稿も削除できます）
- 投稿ごとのリンク（`#post/…`）を共有可能
- スマートフォン表示とダークモードに対応

## 使い方

### A. サーバーで動かす（みんなで共有する）

Node.js 18 以降が必要です。

1. `start.bat` をダブルクリックします
   （コマンドで起動する場合は、このフォルダで `node server.js` を実行します）
2. ブラウザで <http://localhost:3000/> を開きます
3. 終了するときは、黒い画面で `Ctrl + C` を押します

投稿データは `data/posts.json` に、画像は `data/images/` に保存されます。

#### 同じネットワーク（LAN）の人にも見せたい場合

初期設定では、このパソコンからしか開けません（安全のため）。
ほかの端末からも使うときは、待ち受けアドレスを変えて起動します。

PowerShell の場合：

```powershell
$env:HOST = "0.0.0.0"; node server.js
```

ほかの端末からは `http://<このパソコンのIPアドレス>:3000/` で開けます。
Windows のファイアウォールで許可を求められたら、プライベートネットワークのみ許可してください。

### B. ファイルを直接開く（ひとりで試す）

`public/index.html` をブラウザで直接開くと「ローカルモード」で動きます。
投稿はそのブラウザの中（IndexedDB）にだけ保存され、ほかの人には見えません。
ローカルモードでは削除キーは使わず、確認だけで削除できます。

## 設定（環境変数）

| 名前 | 内容 | 既定値 |
| --- | --- | --- |
| `PORT` | 待ち受けポート | `3000` |
| `HOST` | 待ち受けアドレス | `127.0.0.1` |
| `ADMIN_KEY` | 管理者キー。削除キーの代わりに入力すると、どの投稿・返信も削除できます | なし |
| `DATA_DIR` | 投稿データと画像の保存先 | `./data` |

例（PowerShell）：

```powershell
$env:PORT = "8080"; $env:ADMIN_KEY = "長くて推測されにくい文字列"; node server.js
```

## 制限

| 項目 | 上限 |
| --- | --- |
| 画像の形式 | JPEG / PNG / GIF / WebP |
| 画像の大きさ | 5MB（GIF 以外は自動で縮小して収めます） |
| タイトル | 60 文字 |
| 名前 | 30 文字 |
| 本文 | 2000 文字（返信は 1000 文字） |
| 返信 | 1 投稿あたり 300 件 |
| 投稿数 | 1000 件（超えると、最後に動きがあった時刻が古いものから自動で消えます） |
| 連続投稿 | 同じ接続元から 1 分間に 10 回まで |

## 安全のための仕組み

- 画像の種類は、ファイル名や申告ではなく中身の先頭バイトで判定します（SVG など、スクリプトを含められる形式は受け付けません）
- 画像は推測できないランダムな名前で保存し、決まった名前の形式以外は配信しません（フォルダの外のファイルは読めません）
- 投稿内容はすべて文字として表示し、HTML としては解釈しません
- Content-Security-Policy などのセキュリティヘッダーを付けて配信します
- 削除キーは scrypt でハッシュ化して保存し、元の文字列は保存しません
- 別のサイトのページからの投稿・削除を拒否します
- 投稿データは一時ファイルに書いてから置き換えるため、途中で止まっても壊れにくくなっています

## インターネットに公開する場合の注意

このままでも動きますが、公開する場合は次の点を検討してください。

- HTTPS 対応のリバースプロキシ（nginx、Caddy など）の後ろで動かす
- 違法な画像や権利侵害への対応方法（通報窓口、管理者による削除）を決めておく
- `ADMIN_KEY` を必ず設定する
- `data` フォルダを定期的にバックアップする

## ファイル構成

```
upload/
├─ server.js        サーバー本体（API・画面・画像の配信）
├─ start.bat        Windows 用の起動ファイル
├─ package.json     npm start 用の設定（依存パッケージなし）
├─ public/
│  ├─ index.html    画面
│  ├─ style.css     見た目
│  ├─ app.js        画面の動き（画像の縮小、投稿、返信、削除、検索）
│  └─ favicon.svg   アイコン
└─ data/            起動すると作られる（投稿データと画像）
```

## データを消して最初からやり直すには

サーバーを止めてから `data` フォルダを削除し、もう一度起動してください。
