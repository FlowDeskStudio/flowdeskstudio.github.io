CSV の書き出し・読み込み

書き出しボタンで下の欄に CSV を表示します。欄に CSV(またはタブ区切り)を貼り付けて「読み込む」と、シート全体を置き換えます。

使い方と関数一覧

基本操作

入力セルを選んでそのまま入力。= で始めると数式になります(例 =SUM(A1:A5)*1.1)。ダブルクリックまたは F2 で編集。
確定 / 取消Enter(下へ)、Tab(右へ)、Esc(取消)
参照の挿入数式の入力中にセルをクリック/ドラッグすると、そのセル番地や範囲が挿入されます。
範囲選択ドラッグ、Shift+矢印、Shift+クリック。行番号・列見出しのクリックで行/列全体、左上隅で全選択(Ctrl+A)。
移動矢印、Tab、Enter、Home、PageUp/PageDown、Ctrl+矢印(データの端へ)、Ctrl+Home
コピー等Ctrl+C / Ctrl+X / Ctrl+V。数式の相対参照は貼り付け先に合わせてずれます。$A$1 のように $ を付けると固定されます。
オートフィル選択範囲右下の小さな四角をドラッグ。数値が 2 つ以上並んでいれば連続データになります。
元に戻すCtrl+Z / Ctrl+Y(または Ctrl+Shift+Z)
削除Delete / Backspace で選択範囲の内容を消去
列幅列見出しの境界をドラッグ。ダブルクリックで自動調整。
行・列ツールバーまたは右クリックメニューから挿入/削除。数式の参照は自動で調整されます。

演算子

+ - * / ^(算術)、&(文字列連結)、= <> < > <= >=(比較)、%(パーセント)

関数

集計SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, COUNTBLANK, PRODUCT, MEDIAN, STDEV, STDEVP, VAR, VARP, LARGE, SMALL, RANK, SUMPRODUCT
条件付き集計SUMIF, SUMIFS, COUNTIF, COUNTIFS, AVERAGEIF(条件は ">=10" や "り*" の形式)
数学ABS, ROUND, ROUNDUP, ROUNDDOWN, INT, TRUNC, MOD, POWER, SQRT, EXP, LN, LOG, LOG10, PI, SIGN, CEILING, FLOOR, SIN, COS, TAN, RAND, RANDBETWEEN
論理IF, IFS, AND, OR, NOT, XOR, IFERROR, ISBLANK, ISNUMBER, ISTEXT, ISERROR, TRUE, FALSE
文字列CONCAT, CONCATENATE, TEXTJOIN, LEN, LEFT, RIGHT, MID, UPPER, LOWER, TRIM, REPT, FIND, SEARCH, SUBSTITUTE, EXACT, VALUE, TEXT
検索VLOOKUP, HLOOKUP, INDEX, MATCH, CHOOSE, ROW, COLUMN, ROWS, COLUMNS
日付TODAY, NOW, DATE, YEAR, MONTH, DAY, WEEKDAY, DAYS, EDATE(2026/10/9 の形式で入力すると日付になります)

エラー表示

#DIV/0! 0 での除算 / #VALUE! 型の不一致 / #REF! 無効な参照 / #NAME? 不明な名前 / #N/A 該当なし / #NUM! 数値が不正 / #CIRC! 循環参照 / #ERROR! 数式の書き方の誤り

このアプリはデータを保存しません。ページを閉じると内容は失われます。残したい場合は CSV として書き出してください。
